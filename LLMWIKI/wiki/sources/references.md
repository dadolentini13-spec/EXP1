# Riferimenti per prompt e orchestrazione

## Riferimenti selezionati
- OpenAI Cookbook: https://github.com/openai/openai-cookbook — esempi, progettazione e valutazione dei prompt.
- Anthropic tutorial: https://github.com/anthropics/prompt-eng-interactive-tutorial — struttura e chiarezza; adattare i consigli specifici di Claude.
- DAIR Guide: https://github.com/dair-ai/Prompt-Engineering-Guide — tecniche e confronti.
- n8n Skills: https://github.com/n8n-io/skills — configurazione, AI, codice e workflow riutilizzabili.
- LangGraph: https://docs.langchain.com/oss/javascript/langgraph/workflows-agents — percorsi e routing; riferimento concettuale, non sostituto delle API n8n.
- Fonte LLM Wiki: [[wiki/sources/karpathy-llm-wiki]].

Queste fonti sono state consultate nella conversazione; un indice non implica una lettura integrale di tutte le repository né la loro accessibilità runtime. Il prossimo agente deve consultare i passaggi pertinenti, indicando versione o data e dichiarando l'eventuale indisponibilità. Non considerare ranking o stelle una prova di correttezza.

Per prompt partire da obiettivo, contesto necessario, vincoli, output e casi di verifica. Aggiungere istruzioni solo se cambiano il comportamento richiesto. Le quattro sezioni del progetto restano il formato delle identità. Vedi [[wiki/common/soul]].
